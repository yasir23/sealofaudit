MRFvsPriceEstimatorTool:WhatCMSActuallyRequires

A price estimator tool and a machine-readable file (MRF) are different requirements. CMS requires both under 45 CFR 180.50: a consumer-facing estimator AND a machine-readable file with negotiated rates. Publishing only an estimator is a common — and finable — misunderstanding.

PurposeConsumer-facing price estimatesRaw data for researchers, payers, CMS crawlers
FormatWeb tool / widgetJSON or CSV, publicly accessible, no login
ContentEstimated out-of-pocket cost for common servicesPayer-specific negotiated rates, cash prices, 70 shoppable services
Required?Yes — shoppable services via online toolYes — the MRF itself

If your hospital built a great estimator but skipped the machine-readable file, you are not compliant. CMS's automated crawler specifically checks for the MRF — it does not grade your estimator. The good news: the MRF is a mechanical fix, and the first step is a free check to see exactly what's missing.
