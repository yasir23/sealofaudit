How CMS Fines Hospitals: Real Penalty Amounts and What Triggers Them

The fear is justified: CMS fines for price transparency non-compliance are real, recurring, and surprisingly large. Here's exactly how the penalty system works.

The Fine: $5,500 Per Day, Per Violation

CMS assesses $5,500 per day per violation. A "violation" isn't one thing — each missing data element, each missing payer, each unreachable file can be a separate violation. The fine accrues daily from the date of non-compliance until the file is fixed and verified.

ScenarioMathTotal
1 violation, 1 week$5,500 × 7$38,500
1 violation, 1 month$5,500 × 30$165,000
3 violations, 1 month$16,500 × 30$495,000
3 violations, 3 months$16,500 × 90$1,485,000

What Actually Triggers a Fine

✗
File not published at all — the clearest violation.
✗
File unreachable — bot-blocking, login walls, or dead links that CMS's automated checker can't read.
✗
Missing required data elements — absent payer rates, cash prices, or shoppable services.
✗
Wrong format — non-machine-readable, malformed JSON/CSV, or human-readable PDF instead of structured data.
✗
Stale data — file not updated after contract renegotiations with payers.
