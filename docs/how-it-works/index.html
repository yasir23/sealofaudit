From "Send Your File" to "Fully Compliant" in 4 Steps

No long contracts. No IT project. Just compliance — fast.

01 — DISCOVERY

Send Your File

Share your MRF URL (usually at yoursite.com/price-transparency) or just your website URL — we'll locate the file for you. If you can't find it, that's already a compliance flag we document.

02 — KICKOFF

Automated Validation

Our validator runs every CMS-required check: payer-specific negotiated charges, discounted cash prices, all 70 shoppable services, gross charges, file format, and public accessibility without login or paywall.

03 — EXECUTE

Expert Review

A compliance analyst reviews the automated findings, confirms what CMS would actually cite, and prioritizes fixes by risk level. This is where machine speed meets human judgment.

04 — DELIVER

Report & Remediation

You get a clear report with red flags and a remediation guide. If you want, we fix the file end-to-end and verify CMS-crawler access — with a 30-day re-check to prove you're clean.

What the Validator Checks

Every check maps to a CMS requirement under 45 CFR §180.50. Missing any one is a potential $5,500/day violation.

✗ Payer-specific negotiated charges for all plan types
✗ Discounted cash prices for all items & services
✗ All 70 CMS-required "shoppable services"
✗ Gross charges for every item & service
✗ De-identified minimum & maximum negotiated rates
✗ Proper format (JSON/CSV, machine-readable)
✗ File publicly accessible without login or paywall
✗ 30+ additional required data elements per CMS spec
