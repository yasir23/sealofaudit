Questions we get from small facilities

We are a 25-bed critical access hospital. Is a machine-readable file really required?

Yes. The requirement in 45 CFR §180.50 applies to each hospital operating in the United States. Bed count affects the maximum daily penalty under §180.90, not whether your file must be published and machine-readable.

We published the file. Doesn't that make us compliant?

Publishing a file and publishing a valid file are different things. CMS's automated review reads the file itself — schema, required elements, in-network file references. A file that is present but malformed is treated the same as a missing one.
